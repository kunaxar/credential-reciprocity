# Where can I use this credential?

A mobile-first prototype. A worker opens a credential and sees where it works, what extra steps a place needs, and what is not confirmed. The same answers show up when searching jobs.

- Entry 1: credential detail, "Where can I use this?" panel
- Entry 2: job search, each job shows which of your credentials count there

The worker, employers and jobs are fictional. Verdicts for the five sample credentials come from the official sources linked in the app and were read on 28 Oct 2026. Rules change, so confirm with the licensing office or employer. Nothing is sent anywhere.
