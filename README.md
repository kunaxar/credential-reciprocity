# Where can I use this credential?

A mobile-first prototype. A worker opens a credential and sees where it works, what extra steps a place needs, and what is not confirmed.

- Entry: credential detail, "Where can I use this?" panel with per-place verdicts, next steps and official sources

The worker and employers are fictional. Verdicts for the five sample credentials come from the official sources linked in the app and were read on 28 Oct 2026. Rules change, so confirm with the licensing office or employer. Nothing is sent anywhere.
